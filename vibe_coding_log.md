# Vibe Coding Log

This file records user prompts and program responses created by `harness.c`.

Entries are appended in the format:

- User: <input>
- Program: <response>
User: 2 + 3
Program: Result: 5

User: hello there
Program: Hello! Nice to meet you.

User: something else
Program: You said: something else

User: exit
Program: Program exiting.
